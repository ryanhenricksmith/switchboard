# Security policy

Switchboard reads local AI-agent transcripts, so privacy and path-handling bugs are treated as security-sensitive.

Please do not open a public issue for a vulnerability. Use GitHub's **Report a vulnerability** flow under the repository's Security tab to submit a private advisory. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not attach real transcripts or credentials; use a minimal synthetic fixture.

The latest release is the only supported version during the project's early development.
